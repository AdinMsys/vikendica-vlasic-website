# Vikendica na Vlašiću – holiday cabin website

A one-page website for a mountain cabin rental in Gostilj on Vlašić, near Travnik (Bosnia and Herzegovina). It gives guests everything they need to decide and book: photos, what the cabin offers, the price, directions, answers to common questions, and a quick way to send a booking inquiry.

## Features

- **Booking inquiry** – guests pick arrival and departure dates, and the page calculates the total price (100 KM per night). The form checks the input, then sends the inquiry to Viber or copies it for any other messenger.
- **Photo gallery** – real photos of the cabin, with a full-screen viewer and next/previous navigation (keyboard arrows work too).
- **Directions** – address and a Google Maps link.
- **FAQ** – expandable answers to the questions guests ask most.
- **Works on phone and desktop** – responsive layout with a mobile menu.
- **Search-engine friendly** – page description, Open Graph tags and structured data (schema.org).

## Built with

- HTML, CSS and plain JavaScript in a single file, with no frameworks or build step
- Developed with AI assistance (Claude): I defined the requirements and content, reviewed the output and tested it on phone and desktop

## Run it

Open `index.html` in any browser.
